FrameFlow 1.5.1 — 本地课程视频剪辑

V1.5.1 维护：手动保存兼容版本3的图片项目；新增独立开发配置与Windows迁移开发工具，不改变剪辑流程。

V1.5.0 更新：视频名悬浮显示完整名称；时间线可跨视频拖动定位，播放中拖动后恢复播放；模糊默认/上限10；批量打码默认目标整段生效；新增可自由缩放的图片遮挡。图片内嵌项目保存，PNG透明区域保留，已接入真实预览与导出。无画面处理且参数兼容时复制视频流拼接和定长分段。
新项目格式为版本3，可读取旧版本1/2；请勿用旧版程序编辑新项目。

V1.4.2：时间轴最右端增加“总时长 HH:MM:SS”，与15分钟刻度分行显示；放大后可横向滚动到末端查看。

适用：64 位 Windows 10 / 11。不需要安装 Node、Python、FFmpeg 或其他开发环境。

安装版：如果你下载的是 Setup.exe，双击后按中文安装向导操作，可选安装位置、桌面快捷方式和开始菜单入口，详见“安装与卸载说明.txt”。安装后从快捷方式启动，可通过 Windows 设置卸载。
以下 ZIP 启动步骤仅适用于原便携版，不是安装版的安装步骤。

启动：
1. 右键 ZIP →“全部解压”，选择本地磁盘上的文件夹，例如 D:\FrameFlow。
2. 打开解压后的 FrameFlow-Windows-x64，双击 FrameFlow.exe。
3. 不能在 ZIP 预览窗口内直接运行；不要单独移动 exe。DLL、resources、locales 必须与程序一起保留。

首次使用：
导入视频 → 调整顺序与勾选 → 添加纯色/模糊/马赛克区域 → 拖动时间条两端设置生效时间 → 片段处理 → 选择输出目录和时长 → 确认真实导出 → 处理结果。
Windows 版本已内置 FFmpeg 与 FFprobe，处理在本机完成。处理结果中的 MP4 是实际文件，可以通过“定位文件”找到。
播放器无法直接解码的格式会生成兼容播放副本，首次准备可能较慢；正式导出始终读取原素材。

V1.4.1 时间线修复：
- 视频、打码时间条、刻度、播放指针共用全局时间坐标，消除轨道偏移。
- 每15分钟显示刻度；支持1×/2×/4×/8×时间线缩放及整体横向滚动。
- 播放头时间显示项目全局时间；播放器仍显示当前视频局部时间。

V1.4 更新：
- 拼接和画面适配都可以独立勾选、取消，状态随项目自动保存。
- 取消拼接后，各视频分别分段，输出连续编号；取消适配后保留原画面尺寸。不同尺寸不能在关闭适配时强行拼接，会提示开启适配或改为分别处理。
- 新项目默认分段时长为45分钟，支持自行修改；旧项目保留你已保存的时长。
- 未启用任何打码区域且参数兼容时，优先直接复制 H.264/H.265 视频流；不改变原视频画质。需要改变画面尺寸、编码参数不兼容或检测到异常码流时，明确提示并自动重编码。
- 输出仍进行解码核验，因此不是只复制文件；损坏码流自动尝试容错解码重编码。无法恢复的素材会报告失败，不把未通过核验的结果发布为成品。容错可能跳过损坏帧，请查看警告并检查输出。
- 结果页显示“输出用时：XX分XX秒”，按开始处理至完成清理的实际耗时计算，完成后不会继续增长。

项目与安全：
- 自动保存当前项目，再次启动恢复素材顺序、打码区域与时间范围、片段设置；不要删除或移动源文件。失效素材可重新定位。
- “新建项目”会在确认后替换当前自动恢复项目，不是多项目管理功能。
- 自动保存通常位于 %APPDATA%\frameflow\session.json；偏好位于同目录 preferences.json。
- 记住上次导入文件夹、输出目录、基础名称；课程视频会命名为“课程视频_001.mp4”等。
- 同名课程片段会阻止导出，不会覆盖源文件和已有结果。请更换名称或输出目录。
- 可取消任务、修正设置后重试。正常取消会清理本次临时文件；强制结束进程或断电可能留下输出目录下的 .frameflow-* 临时目录，请确认没有任务运行后再处理。

本版边界：
- 提供课程视频的定时打码、排序拼接、补黑边和定长分段；不包含多轨剪辑、转场、字幕制作、手动裁掉片头片尾。
- 输出 MP4。直接复制保留 H.264/H.265 和 AAC（无音轨则保留无音轨）；需要重编码时使用 H.264，必要时统一 AAC。开启适配时尺寸跟随第一段勾选视频；关闭适配时保留原尺寸。源编码画质档位无法反向读取，编码前会提示实际规则。
- 兼容无损拼接会在源关键帧处分段，实际时长可能与目标有偏差；最后不足目标的片段仍保留。
- HDR 素材如需重新编码，会提示先转为 SDR，暂不做自动 HDR 色调映射。
- 重新编码临时文件可能需要约 2–3 倍输出空间；剩余空间会在开始前估算检查。

验证说明：
已在 macOS 桌面外壳验证共享应用代码、实际 MP4 编码、播放跳转与恢复；Windows x64 可执行文件架构、引擎校验值及 ZIP 完整性会随发行构建检查。
本机没有 Windows 实机环境，Windows 10/11 的路径、驱动和硬件编码兼容性仍需在你的电脑上验收。硬件编码不可用会自动改用软件编码。
本自用开发包未做商业代码签名。如系统弹出安全提示，请核对来源和校验值；不建议关闭系统安全防护。

应用源代码为自用项目；第三方组件按各自许可证使用。FFmpeg 许可证与发行说明位于 resources\app\runtime，依赖来源见 DEPENDENCIES.md。
