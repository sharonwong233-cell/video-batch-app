# FrameFlow V1.4.1 Windows 安装版

日期：2026-09-11。应用功能仍为已交付的 V1.4.1；本次新增安装、快捷方式和卸载流程，不更改视频处理引擎。

发布者名称更新：Windows 已安装应用中的发布者、安装 EXE 文件属性中的公司名称均设为 `SharonWong`。仅修改显示信息，不添加数字签名；系统安全提示仍可能显示未知发布者。重新生成的独立 Setup.exe 为此更新后的交付文件，之前的 ZIP 保留为历史版本。

## 安装过程

欢迎 → 组件选择 → 安装目录 → 安装进度 → 完成。

- 中文向导；当前用户安装，不请求管理员权限，不创建自启动任务，不更改文件关联或系统 PATH。
- 主程序和内置视频引擎为必选；桌面快捷方式、开始菜单入口均可分别勾选或取消，默认勾选。
- 默认目录：`%LOCALAPPDATA%\Programs\FrameFlow`。可选择其他可写入的、名称为 FrameFlow 的空文件夹。
- 完成页“立即启动 FrameFlow”可选，默认不勾选。
- 重装读取原安装目录和快捷方式选择；取消原先勾选的快捷方式会移除安装器之前创建的入口。
- Windows 设置的应用列表登记 FrameFlow，可从此卸载，也可运行安装目录的 `Uninstall.exe`。

## 数据与安全

- 不直接覆盖便携版或其他非空目录。变更已有安装的位置前需卸载旧安装。
- 安装、卸载前检查主程序是否被占用，不自动结束进程；用户可以退出应用后重试。
- 卸载按构建时生成的文件清单逐个删除程序文件，目录只在为空时删除，不使用递归清空。
- 不删除 `%APPDATA%\frameflow` 的配置、源素材或导出视频。存放在安装目录、且与应用文件不同名的额外文件会保留。
- 尚未商业代码签名，Windows 可能提示未知发布者；不得因此关闭系统安全防护。请核对本次交付来源和配套 SHA-256。

## Windows 验收清单

1. 默认安装：选择桌面、开始菜单入口，两处均可启动；Windows 应用列表可见 FrameFlow。
2. 取消两个快捷方式：安装仍成功，两处不创建入口，安装目录中的程序可启动。
3. 自定义目录及中文用户名路径：安装、导入、实际导出可用。
4. 同目录重装：读取原选择；取消快捷方式后相应入口移除；项目仍恢复。
5. 运行中安装或卸载：提示先退出；取消操作不强杀应用。
6. 卸载：程序文件与安装器创建的快捷方式移除；项目配置、额外测试文件和源/导出视频保留。
