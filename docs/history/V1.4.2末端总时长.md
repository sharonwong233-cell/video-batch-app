# V1.4.2 时间轴末端总时长

2026-09-14。

- 时间轴末端新增“总时长 HH:MM:SS”，按时间轴上全部视频的时长求和，与两条轨道共用同一坐标；不是只显示当前视频时长，也不是导出用时。
- 原有每15分钟刻度保留，总时长在刻度文字下方单独一行，避免末尾接近刻度时文字重叠。
- 缩放、窗口宽度变化及滚动后仍对齐时间轴末端。时间轴超出视口时，横向滚动到末端查看。空素材状态不显示虚假时长。
- 本轮不修改视频引擎、导出流程或安装压缩方式；发布者名称继续使用 SharonWong，仍为未签名自用版本。

验证：本机旧 Electron 桌面测试运行时无法启动，改用隔离 Chrome 对同一页面验证。复用既有时间线坐标测试，增加总时长文字、末端坐标、与刻度不重叠、空状态及15分钟前后边界检查。浏览器中的时长夹具仅用于布局检查；未声称重新完成真实导出或 Windows 安装验收。源码语法及安装包完整性另行核验。

记录：`验收记录/V1.4.2/`、`验收记录/V1.4.2安装包/`。

本次浏览器布局验收通过 2210 次坐标与文字断言，覆盖不同窗口宽度、缩放、滚动、极短素材、899/900/901 秒边界及空状态。最终截图已人工检查，末端总时长未与刻度重叠。
