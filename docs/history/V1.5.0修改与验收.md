# V1.5.0 交互与图片打码

2026-09-21。发布者显示名 SharonWong，仍为未签名自用版本。

## 六项修改

1. 素材列表、当前画面名称、视频时间条都可悬浮查看完整视频名称。
2. 视频轨道、刻度、播放头和打码轨道空白处可拖动定位，支持跨视频及缩放后的时间换算。原本正在播放时，放开后恢复播放；原本暂停则保持暂停。打码区域本身及左右端仍用于修改区域生效时间，不与播放拖动抢占。
3. 模糊默认强度10、上限10。旧项目超过10的模糊强度读取时自动限制为10。马赛克继续使用原有1–30范围。
4. 无启用打码、无实际补边/画面尺寸转换、编码参数兼容时，拼接与定长分段使用视频流复制。不仅在取消“画面适配”时生效：适配已勾选但不需要改变画面，也可直接复制。相同的旋转/SAR元数据不再独自触发重编码。不兼容或异常码流仍提示并回退重编码；输出仍需解码核验，切点依赖关键帧。未新增任意时间裁剪工具。
5. 批量应用保持区域位置、尺寸、类型与启用状态，目标视频默认从0秒至自身结尾生效，不复制源视频的局部起止时间；源视频不变。目标视频之后可继续独立编辑。
6. 新增“图片”遮挡，选择 PNG、JPG、WebP，画面上可拖动、通过四角或宽高输入自由缩放（宽高可分别调整）。PNG透明区域保留。图片已接入画布、FFmpeg真实预览、真实导出、区域复制、批量应用、撤销与项目恢复。

## 图片与项目

- 图片在导入时转换为 PNG，长边最多1280像素；原文件不改动。输入文件最多20MB，单张转换后约2MB以内，项目最多20张、图片数据合计最多8MB。超限有提示，不静默丢失图片。
- 图片在项目内嵌保存，相同图片批量应用仅引用一份，不依赖原图片文件。源视频仍使用原来的文件定位机制。
- 新项目格式版本3，继续读取旧版本1/2；旧软件不支持版本3，避免把图片区域误当成纯色后覆盖保存。缺少图片时阻止导出，不静默漏遮挡。
- 本次复用已有控件、FFmpeg和标准文件选择能力；按 ponytail 原则不增加应用运行依赖。
