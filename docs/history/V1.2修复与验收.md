# FrameFlow V1.2 修复与验收

日期：2026-09-09

## 本次修复

1. Windows 本地视频协议增加标准字节区间读取，返回 `Accept-Ranges`、`Content-Range`、`Content-Length` 和 `206 Partial Content`，解决长视频无法前进、后退或拖动定位的问题。
2. 视频时间线恢复显示全部导入视频，并按素材时长比例排列。
3. 当前编辑视频使用高亮边框；未勾选视频在时间线上弱化显示。
4. 当前视频的打码时间范围显示在对应视频片段下方，仍可拖动整体及两端调整。
5. 播放头在总视频时间线中按“前序视频时长 + 当前视频时间”定位。

## 验收范围

- 使用两段真实 MP4 同时导入。
- 验证视频响应可跳转。
- 验证前进一秒、后退一秒和拖动进度条。
- 验证时间线同时出现两段视频。
- 验证当前视频切换状态和打码时间范围缩放。
- 验证画面仍可绘制到 Canvas。

当前版本仍为可交互原型，不执行真实编码或视频导出。
