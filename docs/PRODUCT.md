# 产品需求基线（截至1.5.1）

依据用户已确认反馈和现存实现重建，用于交接；不是原始PRD副本。较新的用户意见覆盖较旧意见。

## 目标与边界

闭源自用、离线课程视频批量处理桌面软件。Windows 10+ x64为当前交付；Mac Intel及Apple Silicon为历史期望，双架构发行未完成，最低macOS版本在现存文件中没有可核验的最终结论，标记待确认。选择对应系统的发行包，不在Windows上运行Mac二进制。

## 核心流程

素材处理 → 片段处理 → 导出监控 → 处理结果。顶部只保留“新建项目”，四步入口固定在页眉下方右侧。初始无示例素材，导入区域明显高亮，其余功能降低对比度并禁用不可用操作。

1. 导入/拖入：支持多素材、素材区整块接收拖入，记住最近文件位置；选中/未选中状态明确；截断名称可悬浮查看。播放、前进/后退、拖动定位应对应真实画面。
2. 遮挡：每个视频独立编辑区域，也可批量应用；纯色无透明度控件；模糊1–10默认10；马赛克；图片可移动缩放并保留透明。后续意见已明确允许区域独立起止时间，覆盖最早“不需要起止时间”的决定。批量应用目标默认整段生效，源区域时间保持。
3. 时间线：全素材视频条、当前素材区域条、刻度和播放头同一时间坐标；每15分钟一刻度、末端总时长；支持缩放/横向滚动。区域条编辑时间、其余轨道拖动定位，播放中放开拖动后继续播放。
4. 片段处理：拼接与画面适配自由勾选/取消；默认保持比例补黑边；默认定长45分钟可修改，尾段保留；不要求精确到帧。默认输出以第一段参数为基线；不保留多音轨、字幕、章节和其他不需要的元数据。实际码率/画质可能有编码偏差，源码并没有额外的画质档位选择控件。
5. 输出位置/名称记住上次选择，输出如 `课程视频_001.mp4`。如已同名拒绝覆盖并提示调整名称；当前并未实现自动跳过已存在编号续写。
6. 性能：无启用打码且无需实际补边/尺寸转换，兼容H.264/HEVC + 可选AAC素材用stream copy拼接/分段；不兼容或损坏提示后容错重编码；不要承诺所有格式都能无损拼接。
7. 真实效果预览、实际进度/取消、真实文件列表、打开输出位置，结果显示“输出用时：XX分XX秒”，完成后用时冻结。
8. 项目关闭后可继续：自动保存素材路径、图片、区域、参数；路径失效提示重新定位，不嵌入原视频。新机器输出目录需重新选择。
9. 发行：Windows中文安装向导、安装目录选择、桌面/开始菜单快捷方式选项、卸载。发布者显示名SharonWong，不等于购买或持有数字签名证书。
