# FrameFlow 1.3 — 真实视频处理版

2026-09-09，由已验收的 V1.2 交互原型继续开发。交付目标是已有课程工作流的真实可用版本，不擅自扩展为通用多轨剪辑器。

## 已完成

- 独立 Electron 桌面应用，不依赖浏览器页面或 localhost 服务。
- 内置 FFmpeg / FFprobe，读取真实视频尺寸、帧率、码率、时长、音视频轨道与旋转信息。
- 全素材时间线、真实播放、前进/后退一秒、进度条定位；定位值做微秒级数值归一，避免浮点计算导致落在相邻帧。
- 每个视频独立的纯色、模糊、马赛克区域；整段/指定时间生效，支持区域移动缩放、时间范围拖动、复制隐藏删除、批量应用。
- FFmpeg 当前帧处理预览，与真实导出共用打码/旋转/补边滤镜规则，不再用 Canvas 冒充引擎处理结果。最终长视频编码压缩仍可能与静帧有细微区别。
- 按勾选顺序拼接、混合比例补黑边、定长分段、尾段保留；输出实际 H.264 + AAC MP4。
- 默认首个勾选视频的尺寸、帧率与目标码率；尺寸取偶数，元数据缺失与画质档位不可读取等情况在导出前明确说明。
- 真正尝试硬件编码器；不可用时软件编码。运行中硬件失败会重新处理并回退，不是模拟状态切换。
- 原文件不改动，输出同名检查、不覆盖发布、磁盘检查、取消、错误提示、重试、正常临时文件清理。
- 实际输出文件经元数据核验后才展示成功；列表提供大小、时长与定位文件。
- 自动保存当前项目，启动恢复；记忆导入文件夹、输出目录和名称。页眉保留“新建项目”一个功能按钮。
- 原生播放器不兼容的素材可生成本地播放副本，导出始终读取原始视频。

## 验收证据

最终本机自动检查：视频引擎 23 项 + 桌面集成 13 项通过。测试使用程序生成的素材，不使用私人课程视频。

`selftest.cjs` 覆盖：三种打码效果的时间范围、真实 PNG 预览、兼容播放副本、横/竖屏和静音素材、3+3+1 秒分段、H.264/AAC 规格、每个输出的完整音视频解码、硬件失败回退、碰撞拒绝、源文件 SHA-256 不变、取消不发布结果、无损拼接、临时文件清理、项目序列化。

`native-acceptance.cjs` 覆盖：空状态、真实解码帧随前进/快退/进度条变化、播放暂停、全素材时间线、单一顶部按钮、添加区域及时间条、真实预览弹窗、从“开始导出”确认到结果列表的完整流程、自动保存落盘、页面重载恢复。

证据目录：`验收记录/V1.3/`，包括两个 JSON 报告、处理预览、桌面结果截图、三个桌面导出的实际 MP4。报告中的绝对路径保留原测试现场；复制的视频可直接从该目录查看。

验证平台为当前 macOS 桌面环境。同一份应用代码经过 Electron → IPC → FFmpeg → 实际文件 → FFmpeg 全片解码验证。Windows 包的 x64 架构、FFmpeg 发行方 SHA-256 与 ZIP 完整性另行检查；**没有 Windows 实机验收，不能把本机通过等同于所有 Windows 硬件通过**。

## 交付与运行

Windows：完整解压 `FrameFlow-v1.3-Windows-x64.zip`，双击 `FrameFlow-Windows-x64/FrameFlow.exe`。不用手动安装任何开发依赖。保留整个应用目录，不能单独复制 exe。开发包未商业签名，先核对来源；不要为此关闭系统安全防护。

开发代码：`frameflow-core.js` 是项目模型，`frameflow-engine.js` 是视频处理，`frameflow-app.js` 是交互，`windows版/main.js` 和 `preload.js` 是跨平台桌面入口。HTML 名称沿用已验收设计文件，但它现在是桌面应用界面，不承担视频处理。

开发运行可用 `Electron windows版`（需要本机 Electron 与 `runtime/<平台>/` 下的引擎）。在本项目中已安装为本地依赖，未修改全局环境。

引擎自测可用 `node selftest.cjs`，或 `ELECTRON_RUN_AS_NODE=1 <Electron可执行文件> selftest.cjs`。脚本生成独立测试目录，不改动真实课程文件。Windows 发布通过 `zsh 构建Windows开发版.sh` 复用已有 Windows 运行时，必须包含 ffmpeg.exe/ffprobe.exe 才能打包。依赖版本与校验值见 `DEPENDENCIES.md`。

## 尚未包含 / 需要 Windows 验收

- HDR 自动色调映射、多轨剪辑、字幕/转场制作、片头片尾手动裁剪没有加入。本版聚焦已经验收的打码—拼接—定长分段。
- 无损切分取源关键帧，目标时长并非帧精确承诺；码率是编码目标，不保证压缩后逐字节与源一致。
- 非 MP4 等格式首次生成兼容播放副本可能较慢。断电或强杀进程可能留下私有临时目录；不会自动扫描并删除不明文件。
- Windows 10/11 真机需用实际课程验证长视频、中文/外置磁盘路径、NVIDIA/Intel/AMD 硬件编码与导出耗时。
- macOS 用于本轮开发验证，尚未交付 Intel/Apple Silicon 双架构签名安装发行。Windows 当前为便携应用，不是带卸载器的安装向导。
