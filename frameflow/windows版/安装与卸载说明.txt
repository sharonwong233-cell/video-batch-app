FrameFlow V1.5.1 Windows 安装版

安装：双击 FrameFlow-v1.5.1-Windows-x64-Setup.exe，按中文向导操作。
1. 选择组件：主程序必选；桌面快捷方式、开始菜单入口可以分别勾选或取消。
2. 选择安装位置：默认当前用户的 LocalAppData\Programs\FrameFlow；可选择其他可写入的、名称为 FrameFlow 的空文件夹。
3. 查看安装进度。
4. 完成后可勾选“立即启动 FrameFlow”。

仅为当前用户安装，无需安装 Node、Python、FFmpeg 等环境。不提供开机自启动，也不修改文件关联或系统 PATH。
ZIP 传输包中只有安装程序和本说明；先解压，再双击 Setup.exe。安装后无需保留 ZIP。

升级：先在应用中保存并退出，再运行新版安装向导，在原目录覆盖安装。更改安装目录前，请先卸载旧安装版。
从便携版迁移：退出便携版，把安装版装到新的空目录。请勿继续使用旧便携版的快捷方式。两者使用同一当前用户配置位置，安装版会尝试恢复上次项目；不要同时运行。

卸载：通过 Windows 设置中的“应用/已安装的应用”找到 FrameFlow，选择卸载；也可运行安装目录的 Uninstall.exe。
卸载保留 %APPDATA%\frameflow 中的项目配置和偏好，不删除源视频、导出视频或安装目录中额外放入的其他文件。程序文件按打包清单逐个移除，不递归清空用户目录。

系统：64位 Windows 10或以上。安装器启动程序本身是32位兼容引导器，安装的是64位应用。
此自用安装包尚未进行商业代码签名，Windows 可能提示“未知发布者”或信誉警告。先核对文件来源及配套 SHA-256；如被组织策略阻止，请联系管理员，不需要关闭系统防护。
本机已完成交叉编译和包内容核验；Windows 真机上的安装、快捷方式与卸载仍待验收。
